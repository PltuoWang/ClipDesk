# ClipDesk 2.1 · 视频下载工作空间

Windows x64 桌面软件。红色图标、原生窗口、YouTube / Bilibili 下载、电脑微信视频号捕捉、码率选择、有声 MP4。头像使用 Haifeng 提供的照片，署名为 `vibe coding by Haifeng.`。


## 下载 Windows EXE

请在 [Releases](https://github.com/PltuoWang/ClipDesk/releases) 下载最新版 EXE。可直接运行，无需安装依赖。二进制和运行组件不放入 Git 源码历史。

## 打开软件

双击交付的 `ClipDesk-2.1.0.exe`。无需另装 Node.js、FFmpeg 或 yt-dlp。首次打开会释放运行文件，稍后显示主窗口；之后启动会复用运行文件。

程序尚未购买代码签名证书，Windows 可能显示发布者未验证。

## 保存地址在哪里

- 设置 → 下载与保存 → 选择文件夹，可以更改默认保存位置。首次默认使用 Windows 的“下载”文件夹；若 Windows 下载文件夹已经迁移到 D 盘，程序会使用迁移后的位置。
- **每次下载都打开 Windows 保存对话框**。默认文件名来自视频名称，你可以更改文件夹和文件名。首次打开使用默认保存文件夹，以后使用上一次确认的保存文件夹，并在重启后保留；取消对话框不会创建下载任务或改变记忆的位置。
- 完成后在下载记录查看完整路径，点击“打开视频”或“打开文件夹”。
- 移除下载记录不会删除桌面版保存到所选位置的视频。

## YouTube / Bilibili

1. 粘贴 YouTube、Shorts 或 Bilibili 视频链接（BV / av / b23.tv），点击“解析视频”。
2. 选择源视频实际可用的清晰度、格式和视频／音频码率。
3. 点击“选择位置并下载”，在保存窗口确认位置。

视频和独立音轨自动合并。导出以 H.264 / AAC MP4 为兼容目标，只有同时验证到画面和音轨才显示成功。兼容的原编码可以直接保留，其他编码自动转换。源文件没有声音时会提示失败，不制造静音音轨。需要可以访问 YouTube 的网络；必要时在“网络设置”填写已有的 HTTP / SOCKS5 代理。Bilibili 默认直连；填写代理时优先使用填写的代理。Bilibili 分 P 链接只下载指定的一 P，没有 p 参数时下载第一 P。最高可用清晰度以平台实际返回的格式为准。登录、私人视频和 DRM 限制会显示错误。

视频目标码率：原画质优先、1 / 2.5 / 5 / 8 / 12 / 20 / 40 Mbps。音频目标码率：原音质优先、96 / 128 / 192 / 256 / 320 kbps。提高码率不会增加源视频细节，实际平均码率随画面变化。

## 电脑微信视频号捕捉

1. 打开左侧“视频号捕捉”，点击“开始捕捉”。
2. 阅读确认窗口，允许后开始捕捉。软件会安装当前 Windows 用户的本地证书，并临时切换系统代理。
3. **关闭并重新打开电脑微信的视频号播放窗口**，播放目标视频。已缓存的旧窗口可能不会触发请求，必要时重新打开视频号。
4. 捕捉列表自动显示视频描述作为名称，以及能获取到的作者、时长和源画质。同一视频重复播放会更新原记录。
5. 点击“导出设置”，默认选择捕捉到的原视频画质、原音质，不重新编码。即使之前为其他网站选过低码率，打开视频号导出设置时也会恢复原画质默认值。可手动更改码率，再点击“选择位置并下载”。保存窗口自动使用解析后的名称，非法文件名字符会被替换。
6. 使用结束点击“停止捕捉”。软件恢复原系统代理，并移除本次安装的本地证书。正常退出同样恢复；独立后台程序处理异常退出，下次启动也会检查残留配置。

捕捉仅解析视频号页面和视频播放数据。其他 HTTPS 连接直接转发；不记录聊天内容、登录 cookie 或完整网络流量。视频地址及解码参数只留在当前进程内存，不保存到下载记录。捕捉列表提供“复制下载链接”；复制的是原始媒体地址，可能限时有效或是加密数据。在其他软件中打开加密地址可能无法播放，使用 ClipDesk 下载可自动处理。仅下载当前客户端提供、可正常播放的媒体，不处理直播流或观看权限受限的内容。

部分微信版本、缓存行为或代理策略可能影响捕捉。若没有记录，请重新打开播放窗口。若出现证书错误或网络异常，停止捕捉再重试。捕捉期间原有系统代理会临时被切换，停止后恢复；若其他程序在期间重新修改系统代理，恢复过程会保留其他程序的新设置。

视频号默认以 MP4 容器封装原视频／音频，保持编码和媒体内容不变。HEVC 源视频会保留 HEVC；某些播放器可能需要对应解码器。手动指定码率时转为 H.264 / AAC。无法封装到 MP4 的原编码会提示错误，需要手动选择转码；不会偷偷降低画质。

## 程序数据与源码

设置和任务记录位于 `%APPDATA%\ClipDesk`；运行文件位于 `%LOCALAPPDATA%\ClipDesk\runtime`。最终视频按每次保存窗口选择的位置保存。

源码 ZIP 不含大型 Electron、FFmpeg、ffprobe、yt-dlp。浏览器版仍可运行 `start.cmd`（首次安装下载组件）；桌面原生功能需用 Electron 运行。

源码开发：安装 Node.js 24+，运行 `npm install`，再安装 Electron 44.5.1 开发依赖。运行 `node setup.mjs` 安装下载工具，运行 `npx electron .` 启动桌面版。运行 `npm test` 验证核心流程。浏览器模式为 `node server.mjs`，默认地址 http://127.0.0.1:8765 。电脑微信捕捉和原生保存窗口仅在桌面版提供。

随包保留第三方许可证；完整 EXE 的工具许可见 THIRD_PARTY_NOTICES.md。

重新打包 EXE：先 `npm install -D electron@44.5.1 resedit@3.1.0`，然后 `node build/package.mjs`；最终文件在源码目录的 `dist/ClipDesk-2.1.0.exe`。Windows 需要自带的 .NET Framework C# 编译器及 PowerShell。
